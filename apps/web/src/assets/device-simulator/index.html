BEE-CORE / CONNECTED DEVICES

Device Simulator

A tiny browser companion to verify the real pairing and device-authentication flow against your Bee-Core tenant. It does not simulate a successful connection locally: requests go to the API you configure.

1 · API and pairing

The QR token is single-use. Pairing creates a pending device; an organization administrator must approve it in the Bee-Core dashboard before heartbeats are accepted.

Important: this is a REST pairing + heartbeat simulator, not a WebSocket test. The current Connected Devices plugin exposes HTTP endpoints for pairing, approval checks and heartbeat; it does not yet expose a realtime WebSocket device channel. The device credential is kept in memory only and is cleared when you disconnect or reload this page.
