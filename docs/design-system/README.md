# Design System Documentation

Bee-Core frontend design is governed by two complementary mandatory guides:

1. [Global Bee-Core Design System](./bee-core-design-system.md) — Page System (Layer 1), shared UI component contracts (Layer 2), accessibility, responsive behavior, localization and implementation workflow.
2. [Midnight Template Style Guide](../../apps/web/src/app/templates/packages/midnight/STYLE-GUIDE.md) — Midnight dashboard visual identity, current palette, semantic token contract and component-specific visual rules (Layer 3).

Every new or substantially modified dashboard feature must read both documents and follow the active template's visual guide. Midnight is the current target for this harmonization effort. The global guide remains template-neutral.

These documents describe the normative target and explicitly distinguish existing implementation from gaps still to be implemented. They do not imply that every documented shared primitive or semantic token already exists in code.
